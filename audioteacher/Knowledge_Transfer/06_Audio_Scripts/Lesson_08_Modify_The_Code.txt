Suppose business requests adding a new dimension, such as DIM_PROMOTION.
First, create a new SQL migration file sql migrations 005_create_promotion dot sql.
Second, add raw promotion data generator in src etl seed_data dot py.
Third, create load_promotions function inside src etl dimensions_loader dot py and append promotion surrogate key to FACT_SALES_ORDER_LINE.
Fourth, run pytest tests to verify that all 13 test suites pass cleanly.
Let's pause and understand this with an example. Adding a dimension expands business reporting capabilities without breaking existing fact order line schema.
