# Enterprise Sales Analytics - Junior Developer Knowledge Transfer Suite

Welcome to the Knowledge Transfer (KT) documentation suite for the Enterprise Sales Analytics Data Warehouse. This curriculum is designed to guide a junior developer from foundational business context through architecture, data modeling, code execution, testing, debugging, and safe maintenance.

---

## Learning Path & Module Curriculum

| Module | Title | Primary Learning Objective |
| :--- | :--- | :--- |
| [01](01-project-and-business-overview.md) | Business & Domain Overview | Understand the business objectives, sales model, and analytical goals |
| [02](02-architecture-and-component-map.md) | Architecture & System Map | Learn the high-level data warehouse layers and module boundaries |
| [03](03-repository-navigation-guide.md) | Repository Navigation Guide | Map physical files to logical components |
| [04](04-data-model-and-scd-guide.md) | Data Model & SCD Policy Guide | Master Kimball dimensional schemas, SCD Type 1/2, and bridge tables |
| [05](05-end-to-end-data-flow-walkthrough.md) | Data Flow Walkthrough | Trace a single sales order line end-to-end through the warehouse |
| [06](06-code-walkthrough.md) | Source Code Walkthrough | File-by-file code explanation of loader and analytics modules |
| [07](07-local-setup-configuration-and-run-guide.md) | Setup & Run Guide | Step-by-step instructions to run the local pipeline and CLI tools |
| [08](08-testing-and-validation-guide.md) | Testing & Validation Guide | Understand pytest suites, data quality checks, and reconciliation |
| [09](09-debugging-and-troubleshooting-guide.md) | Troubleshooting Guide | Diagnose common ETL failures, reject logs, and schema issues |
| [10](10-safe-change-playbook.md) | Safe Change Playbook | Step-by-step procedures for adding columns, rules, or metrics |
| [11](11-deployment-and-operations-awareness.md) | Deployment & Ops Awareness | Understand CI/CD, runbooks, monitoring, and rollbacks |
| [12](12-known-issues-faq-and-glossary.md) | FAQ & Technical Glossary | Project terminology, acronyms, and common questions |
| [13](13-hands-on-exercises.md) | Hands-on Exercises | Interactive practical labs to build confidence |
| [14](14-knowledge-check-with-answers.md) | Knowledge Check | Self-assessment questions with detailed answers |
| [15](15-reverse-kt-and-competency-checklist.md) | Reverse-KT & Competency | Final sign-off rubric for independent maintenance |
